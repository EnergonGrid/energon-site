WALLET SETUP

Flare Mainnet · Start Here

This guide walks you from wallet installation through your first verified Energon Cube. Bifrost is the recommended mobile wallet, followed by MetaMask. Ledger is available for users who prefer hardware-wallet signing.

Before You Begin: Install wallets only from their official website or official app-store listing. Write your recovery phrase down and keep it offline. Never send it to anyone, never enter it into Energon, and never type it into any website.
Funding: You need FLR on Flare Mainnet for network fees and the mint transaction. When withdrawing FLR from an exchange, confirm that the withdrawal network is Flare. For a first transfer, consider sending a small test amount before transferring the rest.

Option A — Bifrost Wallet · Recommended

  1. Install Bifrost Wallet from the official app-store listing and create a new wallet, or import a wallet you already control.
    iOS App Store Android / Google Play
  2. If creating a new wallet, write the recovery phrase down and store it securely offline. Complete Bifrost's backup/verification process before funding the wallet.
  3. Open Bifrost and make sure you are using the account you intend to use for Energon.
  4. Select Flare / Flare Mainnet.
  5. Tap Receive and copy your Flare address. Confirm the address carefully before sending funds to it.
  6. Fund with FLR: Send or withdraw FLR using the Flare network to that address. If this is your first transfer, consider sending a small test amount first.
  7. Wait for the FLR balance to appear before continuing.
  8. Add EON if it is not already visible: open Receive, search for Energon or EON, then choose Add Custom Token if needed. Select Flare and paste:
    0x9458Cbb2e7DafFE6b3cf4d6F2AC75f2d2e0F7d79
    Verify the token shows EON before adding it.
  9. Open Bifrost's built-in Web3 browser.
  10. Enter the official Energon mint URL:
    https://mint.energon.app/mint
  11. Verify the URL before connecting. Tap Connect Wallet on the Energon dApp and approve the connection request inside Bifrost.
  12. Make sure the connected account is the same address you funded and that the selected network is Flare.
  13. Before minting, confirm this wallet does not already hold an Energon Cube. If it already holds one, stop here.
  14. Follow the Energon dApp instructions to mint one Energon Cube.
  15. Review the transaction details in Bifrost, confirm you are signing on Flare, and approve the transaction.
  16. Wait for the transaction to confirm. Do not submit a second mint simply because the wallet display is slow to update.
  17. If the wallet display has not updated, use Flare Explorer to inspect the confirmed mint transaction and on-chain Cube activity:
    Open CUBE on Explorer
  18. Confirm that EON is visible in your wallet. If the token is not displayed automatically, use the EON contract address above to add it manually.
  19. Return to Energon and reconnect the same wallet. The intended Guardian state is COHERENT — exactly one Energon Cube.

Option B — MetaMask

  1. Install MetaMask from the official MetaMask source or official app-store listing, then create or import your wallet.
    Desktop / Browser Extension iOS App Store Android / Google Play
  2. If creating a new wallet, write the recovery phrase down and store it securely offline. Complete MetaMask's backup/verification steps before funding the wallet.
  3. Open the network selector. If Flare is available, add/select it. Otherwise choose Add a custom network and enter:

    Network name: Flare Mainnet
    RPC URL: https://flare-api.flare.network/ext/C/rpc
    Chain ID: 14
    Currency symbol: FLR
    Block explorer: https://flare-explorer.flare.network
  4. Switch MetaMask to Flare Mainnet.
  5. Select the MetaMask account you intend to use for Energon and copy its receive address.
  6. Fund with FLR: Send or withdraw FLR using the Flare network to that address. If this is your first transfer, consider sending a small test amount first.
  7. Wait for the FLR balance to appear before continuing.
  8. Add EON: use MetaMask's token import / custom token option and paste:
    0x9458Cbb2e7DafFE6b3cf4d6F2AC75f2d2e0F7d79
    Verify EON and 18 decimals if MetaMask displays those fields, then import the token.
  9. On MetaMask Mobile, open the built-in browser. On desktop, open the Energon mint site in the browser where the MetaMask extension is installed.
  10. Navigate to:
    https://mint.energon.app/mint
  11. Verify the URL, then tap/click Connect Wallet and approve the connection.
  12. Confirm that MetaMask is connected with the correct account and Flare Mainnet.
  13. Before minting, confirm this wallet does not already hold an Energon Cube. If it already holds one, stop here.
  14. Follow the Energon dApp instructions to mint one Energon Cube.
  15. Review the transaction details carefully, confirm the network is Flare, and approve it.
  16. Wait for confirmation. Do not submit another mint merely because the NFT display has not refreshed yet.
  17. If the wallet display has not updated, use Flare Explorer to inspect the confirmed mint transaction and on-chain Cube activity:
    Open CUBE on Explorer
  18. Confirm EON is visible in MetaMask. If necessary, import EON again using the official contract address above.
  19. Return to Energon and reconnect the same wallet. The intended Guardian state is COHERENT — exactly one Energon Cube.
MetaMask network settings are device-specific. If you use the same account on another device, you may need to add Flare Mainnet there separately.

Option C — Ledger Hardware Wallet

Ledger keeps transaction signing on the hardware device. For this setup, use Ledger together with MetaMask to interact with Flare and Energon.

Optional Ledger Purchase — Referral Link

  1. Initialize your Ledger using Ledger's official setup process. Write the Ledger recovery phrase down and store it securely offline. Use only Ledger's official companion app for device setup and app installation.
    Official Ledger App Download
  2. In Ledger's official companion app, open the device app manager and install the Ethereum app on the Ledger device.
  3. Install/open MetaMask and connect your Ledger as a hardware wallet.
  4. Select the Ledger account/address you intend to use and verify the address carefully. This is the Ledger-controlled address you will use with Energon.
  5. Add or select Flare Mainnet in MetaMask using the network details above.
  6. Make sure MetaMask is showing the correct Ledger account while Flare Mainnet is selected.
  7. Fund with FLR: send or withdraw FLR using the Flare network to that Ledger-controlled address. Consider a small test transfer first.
  8. Wait for the FLR balance to appear before continuing.
  9. Add EON to MetaMask using:
    0x9458Cbb2e7DafFE6b3cf4d6F2AC75f2d2e0F7d79
    Verify EON and 18 decimals if those fields are displayed.
  10. Open:
    https://mint.energon.app/mint
    in the browser where your Ledger-connected MetaMask is available.
  11. Verify the URL, connect MetaMask, and make sure the selected account is the Ledger-controlled address you funded.
  12. Before minting, confirm that this Ledger address does not already hold an Energon Cube. If it already holds one, stop here.
  13. Follow the Energon dApp instructions to mint one Energon Cube.
  14. When MetaMask requests the transaction, review the details there and then verify the transaction on the Ledger device screen before physically approving it.
  15. Wait for confirmation. Do not repeat the mint simply because the wallet interface has not refreshed yet.
  16. If the wallet display has not updated, use Flare Explorer to inspect the confirmed mint transaction and on-chain Cube activity:
    Open CUBE on Explorer
  17. Confirm EON is visible in MetaMask and return to Energon with the same Ledger account. The intended Guardian state is COHERENT — exactly one Energon Cube.
Never enter your Ledger recovery phrase into MetaMask, Energon, a browser, or any website. Energon will never request it.
